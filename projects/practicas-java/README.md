# Programación en Java

Selección de cuatro ejercicios que exploran programación de consola, orientación a objetos, interfaces gráficas y acceso a datos.

## Proyectos

| Proyecto | Qué muestra | Cómo empezar |
| --- | --- | --- |
| [Calculadora de consola](calculadora-consola/README.md) | Métodos, decisiones, bucles y validación de entrada | `run.ps1` |
| [Modelo de empresa](modelo-empresa/README.md) | Clases, herencia, polimorfismo y colecciones | `run.ps1` |
| [Calculadora de escritorio](calculadora-escritorio/README.md) | Interfaz Swing, eventos e historial | `run.ps1` |
| [Gestión de tienda](tienda-jdbc/README.md) | JDBC, consultas preparadas y operaciones CRUD con MySQL | `run.ps1` |

## Requisitos

- Java 17 o posterior para las aplicaciones de consola, orientación a objetos e interfaz gráfica.
- Java 17, Maven y un servidor MySQL para la aplicación JDBC.
- Windows PowerShell para los accesos directos `run.ps1`. Los proyectos también se pueden compilar desde otros sistemas con los comandos de cada guía.

El material original se realizó durante el ciclo de Desarrollo de Aplicaciones Web. Las descripciones señalan los ajustes que cambian el comportamiento de los ejercicios y facilitan su ejecución.

La práctica de [pruebas unitarias con JUnit 5](../testing-junit/README.md) complementa esta selección. Incluye los dos casos originales de cálculo de remuneraciones, instrucciones de ejecución y resultados documentados.
